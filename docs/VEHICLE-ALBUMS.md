# อัลบั้มรูปรถทั้งเว็บไซต์

อัปเดต 5 พฤศจิกายน 2569 ตามคำสั่งให้ใช้รูปแบบเดียวกับหน้ารายเมือง

- หน้าแรกและหน้ารวมรถ: เปลี่ยนส่วนรูปตัวเลือกรถเป็น `VehicleAlbums` และวางหลังตารางราคารวม
- หน้ารถตู้: เอารูปพรีวิวก่อนราคาออก ใช้อัลบั้มเดิมหลังราคาและแสดงภาพเต็มสัดส่วน
- หน้าเก๋ง/SUV: แทนอัลบั้มรูปคงที่เดิมด้วย `VehicleAlbums` ที่กรองตามประเภทรถ หลังตารางราคา
- หน้ารถบัส: เอารูปรถใน hero ออก และย้ายอัลบั้มเดิมให้ต่อจากส่วนราคาและเงื่อนไขการจอง ไม่มีการสร้างราคาบัสใหม่
- หน้าเส้นทางรวมและหน้าเส้นทางแต่ละรายการ: เพิ่มอัลบั้มหลังตารางราคาหรือส่วนแจ้งให้ยืนยันราคาของเส้นทางนั้น ภาพสถานที่ท่องเที่ยวและจุดรับยังอยู่กับเนื้อหาเดิม
- `VehicleAlbums` อ่านภาพ ประเภทรถ ความจุ และสัมภาระจากข้อมูลกลางเดิม ใช้ `VanAlbum` ร่วมกันสำหรับแถบรูปแนวนอนบนมือถือและ native dialog ขยายรูป ภาพรถใช้ object-contain
- ไม่เพิ่ม dependency ไม่เปลี่ยนราคาและไม่เพิ่มแบบฟอร์มขอราคา

ตรวจ HTTP 200 และลำดับราคา → อัลบั้มบน local: `/`, `/car-with-driver/`, `/van-laos/`, `/car-with-driver/sedan-suv/`, `/car-with-driver/minibus-bus/`, `/travel-with-us/`, `/routes/vientiane-city/`, `/routes/vientiane-vang-vieng/` ส่วนหน้าเส้นทางอื่นใช้ template เดียวกัน

TypeScript และ ESLint ของ app/components ผ่าน ไม่มี error หรือ warning การทดสอบ HTTP ยืนยันการแสดงเนื้อหาและลำดับส่วน แต่ไม่ได้ทดแทนการทดสอบการปัด/แตะจริงในเบราว์เซอร์
