# กรอบสรุปราคาและตารางครบตามเมือง

ปรับล่าสุด: ไฮไลท์ใช้ `PriceHighlights` แบบย่อ หน้าแรกและหน้าจองรถเมืองละ 1 รายการ รวม 3 แถว หน้ารถตู้เมืองละรับ–ส่งเริ่มต้นและเหมาเต็มวัน รวม 6 แถว หน้ารายเมือง 3 แถว ตัดหมายเหตุยาวออกจากไฮไลท์ แต่คงราคาครบและเงื่อนไขในตารางเต็ม หน้าแรกใช้การ์ดรูปเลือกรถ 3 ประเภทแทนอัลบั้มยาว ลิงก์ดูราคาครบจากหน้าแรกไปหน้าจองรถ ส่วนหน้าอื่นพาไปตารางเต็มของหน้านั้น ตรวจ HTTP 200 และจำนวนแถวทั้ง 6 หน้าผ่าน

อัปเดต 5 พฤศจิกายน 2569

- ใช้ `ServicePriceOverview` ร่วมกัน อ่านตัวเลขเวียงจันทน์จาก `data/pricing.ts` และราคาท้องถิ่นจาก `data/city-services.ts` ไม่มีการเปลี่ยนราคา
- หน้าแรกใช้กรอบไฮไลท์แยกเมืองแบบพื้นสว่าง
- หน้าจองรถมีกรอบไฮไลท์ด้านบนและตารางครบด้านล่าง: เวียงจันทน์ยังใช้ PublishedPriceTable เดิม เพิ่มวังเวียง 3 รายการและหลวงพระบาง 4 รายการ SUV อยู่ซ้าย รถตู้อยู่ขวา รายการที่ไม่มี SUV ใช้ขีด “–” ไม่ใช้เลขศูนย์หรือราคาเดา
- หน้ารถตู้มีสรุปไฮไลท์ครบสามเมืองและตารางครบแยกเมือง แสดงเฉพาะราคารถตู้ ข้อมูลรับจากไทยและค่าเพิ่มเดิมระบุชัดว่าใช้กับบริการที่เริ่มรับจากเวียงจันทน์
- หน้าวังเวียงและหลวงพระบางมีกรอบสรุปราคาก่อนปุ่ม LINE แสดงเฉพาะรถตู้ตามบริการจริง รวมถึงช่วงราคาสถานีรถไฟหลวงพระบาง 1,000–1,200 บาท
- หน้าเที่ยวลาวกับเรามีตารางสองเมืองเพิ่มเติมต่อจากตารางเส้นทางเวียงจันทน์
- ทุกตารางระบุเมืองเริ่มรับ ขอบเขตเวลา สิ่งที่รวม/ไม่รวม และการขอราคาหลายวันตามแผน ไม่คัดลอกเงื่อนไขรับฝั่งไทยไปใช้กับอีกสองเมือง อัลบั้มอยู่หลังตารางราคาครบตามเดิม

ตรวจ local หน้าแรก หน้าจองรถ หน้ารถตู้ วังเวียง หลวงพระบาง และเที่ยวลาวกับเรา ได้ HTTP 200 และพบกรอบ/ราคาครบ ตรวจช่วงราคาและ SUV ที่ไม่มีบริการผ่าน ESLint และ TypeScript ผ่าน ไม่มี dependency เพิ่ม ไม่ deploy/push/merge
