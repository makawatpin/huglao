# ส่งงานหน้ารถตู้รายเมือง — 5 พฤศจิกายน 2569

## อัปเดตล่าสุด: อัลบั้มรถอยู่หลังตารางราคาทุกเมือง

ย้ายภาพรถออกจาก hero และย้ายตัวเลือกรถเวียงจันทน์ลงมาหลังตารางราคารวมทันที สองเมืองอื่นใช้ตำแหน่งเดียวกัน อัลบั้มใช้ `VanAlbum` ร่วมกับหน้ารถตู้เดิม: มือถือเลื่อนภาพแนวนอนแบบ snap แตะเพื่อขยาย ปัดซ้าย–ขวาหรือใช้ปุ่มก่อนหน้า/ถัดไปได้ ภาพรถใช้ object-contain เพื่อให้เห็นทั้งภาพโดยไม่ครอป ช่องภาพขยายเป็น native dialog อยู่เหนือ header และรองรับ focus/ปุ่ม Escape ส่วนเวียงจันทน์แบ่งอัลบั้มรถตู้ เก๋ง/SUV และมินิบัส/รถบัส ข้อมูลที่ระบุว่าแสดงตัวเลือกรถก่อนราคาในบันทึกด้านล่างถูกแทนที่ด้วยอัปเดตนี้

## อัปเดตโครงสร้างหน้าเวียงจันทน์: รวมตัวเลือกรถ

หน้า `/vientiane/` เป็นบริการเหมารถเที่ยวเวียงจันทร์แบบส่วนตัว มีส่วน `VientianeVehicleOptions` ก่อนตารางราคา แสดงภาพและตัวเลือกรถตู้ เก๋ง/SUV และมินิบัส/รถบัสครบจากคลังเดิม โดยเรียงรถตู้ก่อน พร้อมภาพภายในและสัมภาระ ตารางเปรียบเทียบเก๋ง/SUV กับรถตู้จากราคากลางเดิม รถบัสเชื่อมรายละเอียดเฉพาะ ไม่แต่งราคาเพิ่ม คง H1 และ title คำหลักเหมารถตู้เวียงจันทร์ ปรับ intro, description, FAQ และ Service schema ให้ครอบคลุมบริการทุกประเภท ไม่มีฟอร์มขอราคา และใช้ LINE เป็นหลัก สองเมืองอื่นยังมีเฉพาะรถตู้ตามเดิม

## อัปเดตล่าสุด: เอากล่องขอราคาออก

ตามคำสั่งเจ้าของ ลบแบบฟอร์มขอราคาทั้งสามเมืองและ component `CityQuoteForm` รวมถึงลิงก์ #quote และข้อความชวนใช้แบบฟอร์ม เอากล่องชวนขอราคาใน footer ออก และลดกรอบกล่องของ LineCta เหลือส่วนติดต่อแบบเรียบ ปุ่ม LINE ยังคงเป็นช่องทางหลัก รายละเอียดเกี่ยวกับแบบฟอร์มด้านล่างเป็นบันทึกของรุ่นก่อนหน้า

## อัปเดตตามคำสั่งล่าสุด: ใช้ LINE เป็นช่องทางหลักทั้งเว็บ

เปลี่ยนปุ่มหลักส่วนหัว เมนูมือถือ แถบล่าง footer และ hero ทั้งสามเมืองกลับมาใช้ `SITE.lineUrl` (`https://lin.ee/sUDSXs5`) ตามคำสั่งเจ้าของล่าสุด เบอร์โทรยังเป็นช่องทางรอง แบบฟอร์มมีปุ่มเปิด LINE ให้ลูกค้าวางและส่งข้อความเอง ไม่อ้างว่าส่งอัตโนมัติ ข้อความด้านล่างที่กล่าวถึงโทรศัพท์เป็น CTA หลักเป็นบันทึกของรุ่นก่อนหน้าและถูกแทนที่ด้วยอัปเดตนี้

## ผลงาน

- ปรับ `/vientiane/` โดยคง URL และใช้ราคาจาก `data/pricing.ts` เดิม ไม่แก้ตัวเลข ตารางเน้นรถตู้และยังเชื่อมตัวเลือกเก๋ง/SUV กับมินิบัส/รถบัส
- เพิ่ม `/vang-vieng/` และ `/luang-prabang/` เป็นบริการเริ่มรับในพื้นที่ แสดงเฉพาะรถตู้ แยกจากเส้นทางเริ่มรับเวียงจันทน์ไปวังเวียง ไม่มี route เดิมที่ให้บริการเริ่มรับในสองเมืองนี้ใน app ก่อนเริ่มงาน
- ทั้งสามหน้าใช้ layout ร่วมกัน: hero → ราคา → ภาพรถ/สัมภาระ → จุดรับ → เส้นทางตัวอย่าง → สิ่งที่รวม/ไม่รวมและเวลา → FAQ → แบบฟอร์ม → ลิงก์รายเมือง
- ใช้ title, description, H1 และ canonical ตามเมือง เพิ่ม Service, BreadcrumbList และ FAQPage ตามเนื้อหาจริง ไม่เพิ่มคะแนน/รีวิว ไม่มีราคาที่คาดเดาใน schema (สองเมืองใหม่ใช้ Service โดยไม่ประกาศ offers)
- แหล่งราคาท้องถิ่นรองรับช่วงราคา 1,000–1,200 บาทของสถานีรถไฟหลวงพระบาง แยกหมวด transfer/charter, ชั่วโมง, ประเภทรถและหน่วยราคา ไม่สร้างส่วนลดหลายวันหรือราคาเส้นทางนอกขอบเขต
- แปลงภาพรถเจ้าของ 8 ภาพเป็น WebP คงสัดส่วน โลโก้เดิมและรายละเอียดรถ ลงทะเบียนในคลังเครดิตภาพ ใช้ภาพประตูชัยและภูมิทัศน์วังเวียงที่มีเครดิต/สิทธิ์เดิม
- เชื่อมหน้าแรก หน้ารถตู้ หน้าเส้นทาง เมนู desktop/mobile และ footer เพิ่ม sitemap สำหรับหน้าใหม่ คงเส้นทางเดิม
- ปุ่มหลักส่วนหัว เมนูมือถือ แถบล่างและ footer ใช้โทร 095-983-2525 ตามข้อมูลกลาง LINE ยังอยู่เป็นช่องทางรองในรายการติดต่อเดิม ไม่มี URL Facebook ที่เดาขึ้น

## ข้อจำกัดและสิ่งที่ยังต้องเติม

1. ยังไม่พบ URL Facebook ที่ยืนยันใน repository จึงใช้โทรศัพท์เป็นช่องทางหลักที่มีอยู่จริง รอ URL จากเจ้าของก่อนเพิ่มปุ่ม Facebook
2. ยังไม่มี backend รับแบบฟอร์ม หน้าเว็บแจ้งชัดว่าเตรียมข้อความเท่านั้น ลูกค้าคัดลอกไปส่งทีมงานผ่านช่องทางที่ใช้อยู่ หรือโทรแจ้งรายละเอียด ไม่แสดงสถานะส่งสำเร็จ
3. ยังขาดภาพสถานที่หลวงพระบางที่ตรวจสิทธิ์ได้ ไม่ใช้ `dest-luangprabang.webp` ซึ่งยังไม่พบหลักฐานสิทธิ์ชัดเจน และไม่ใช้ภาพคนละเมืองแทน ภาพสถานที่เฉพาะบลูลากูน/ผาหนามไซ/น้ำตกก็ไม่ได้เพิ่มโดยเดาสิทธิ์
4. ยังไม่ผ่านการตรวจ desktop/mobile ด้วยสายตาใน browser จริง: เรียกหน้าต่าง VS Code ได้แต่ accessibility ใช้ไม่ได้ และการขอควบคุม Edge หมดเวลา จึงยังยืนยันการจัดวางด้วยภาพ การกดคัดลอก clipboard และการเปิดแอปโทรจริงไม่ได้ การตรวจ HTTP ไม่ทดแทนการตรวจส่วนนี้
5. Turbopack build ล้มด้วย internal error ขณะเปิด process สำหรับ CSS ทั้งในและนอก sandbox จึงใช้ webpack ตรวจ build โดยไม่แก้ build script/config เดิม ไม่ได้สรุปว่าเป็นบั๊กเดิมของโค้ดเพราะไม่มี baseline ยืนยัน
6. sandbox จำกัด DNS ไป Contentful และ loopback จึงใช้การรันที่ได้รับอนุญาตนอก sandbox สำหรับ build ที่ต้องดึงบทความและตรวจ HTTP ไม่เปลี่ยน fallback production ให้ซ่อนข้อมูลที่ดึงไม่ได้
