อัปเดต 2026-09-14 · เอาไฟล์นี้ให้ Claude อ่านตอนเริ่มคุยครั้งหน้า

## ภาพรวม
ระบบหลังบ้านสำหรับออกเอกสารของ HUGLAO อยู่ที่ **https://app.huglao.com** แยกจากเว็บการตลาด huglao.com
พนักงาน login ด้วยรหัสพนักงานกับรหัสผ่าน มี 2 สิทธิ์ คือ Admin และ Staff

| รหัส | เอกสาร |
|---|---|
| DP | ใบรับเงินมัดจำ (ลูกค้า → HUGLAO) |
| RC | ใบเสร็จยอดคงเหลือ |
| IV | ใบแจ้งหนี้ค่านายหน้าถึงเจ้าของรถตู้ (ออกเมื่อค่านายหน้า − มัดจำ > 0) |
| CR | ใบเสร็จรับค่านายหน้าจากเจ้าของรถ (อ้างอิง IV) |
| PV | ใบสำคัญจ่าย (ค่าใช้จ่ายภายใน แนบสลิปได้ 1 รูป ไม่เกิน 5 MB ผูกกับงานได้ถ้าต้องการ) |

## กติกาธุรกิจ
- ราคาขาย = ราคารถ + ค่านายหน้า ค่าเริ่มต้น 25% แก้ไขได้
- มัดจำเท่ากับค่านายหน้า และจ่ายให้ HUGLAO ส่วนที่เหลือลูกค้าจ่ายตรงให้รถ
- เอกสารเป็นไทยและอังกฤษ ใช้เงินบาทเท่านั้น
- เลขที่เอกสารรูปแบบ `CODE-YYMM-NNNN` เรียงต่อเนื่อง ไม่มีเลขขาด
- ไม่มีทะเบียนลูกค้า ให้พิมพ์ชื่อและเบอร์ลงในงานแต่ละงาน ส่วนทะเบียนรถตู้มีอยู่
- ยกเลิกเอกสารได้เฉพาะ Admin และต้องยกเลิก RC ก่อน DP และ CR ก่อน IV
- พนักงานปิดใช้งานได้อย่างเดียว ลบไม่ได้
- หมวด PV: น้ำมัน, ค่าจ้าง/เงินเดือน, ค่าเช่า, ค่าโฆษณา, ค่าน้ำ/ค่าไฟ/อินเทอร์เน็ต, ค่าเดินทาง, ค่าอุปกรณ์สำนักงาน, อื่นๆ
- ทำ PDF โดยเปิดหน้า A4 แล้วสั่ง "พิมพ์ / บันทึกเป็น PDF" จากเบราว์เซอร์

## สถานะ
- เสร็จครบ 4 plan มี tag plan-1-foundation, plan-2-bookings, plan-3-documents และ plan-4-operations
- แก้ปัญหา "This page couldn't load" แล้ว (commit 5bd17c1)
  - สาเหตุคือ Supabase ตอบ 504 เป็นครั้งคราว
  - ตอนนี้ระบบลองดึงข้อมูลใหม่อัตโนมัติสำหรับคำขอแบบ GET/HEAD
  - ถ้า auth ตอบ 504 จะไม่เด้งไปหน้า login แล้ว
  - มีหน้า error ภาษาไทยพร้อมปุ่ม "ลองใหม่"

- ลดการเช็ก auth ซ้ำแล้ว (huglao-app commit "perf(auth): verify JWT locally in proxy with getClaims")
  - proxy ใช้ `getClaims()` ตรวจลายเซ็น token แบบ ES256 ในเครื่อง ไม่ต้องเรียก Supabase
  - `getCurrentStaff()` ในแต่ละหน้ายังใช้ `getUser()` และเช็กว่าพนักงานยังเปิดใช้งานอยู่ ส่วนความปลอดภัยของข้อมูลยังคุมด้วย RLS
  - ทดสอบบนเว็บจริงแล้ว หน้าโหลดปกติ และถ้าไม่ได้ login ระบบพาไปหน้า /login
  - ไม่ได้เปลี่ยน getCurrentStaff ไปใช้ getClaims โดยตั้งใจ เพราะถ้าเปลี่ยน การออกจากระบบจากเครื่องอื่นจะมีผลช้าไปถึงประมาณ 1 ชั่วโมง
