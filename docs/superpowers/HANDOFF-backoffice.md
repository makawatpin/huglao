# HUGLAO Back Office: สรุปสำหรับเริ่ม session ใหม่

อัปเดต 2026-09-14 · เอาไฟล์นี้ให้ Claude อ่านตอนเริ่มคุยครั้งหน้า

## ภาพรวม
ระบบหลังบ้านสำหรับออกเอกสารของ HUGLAO อยู่ที่ **https://app.huglao.com** แยกจากเว็บการตลาด huglao.com
พนักงาน login ด้วยรหัสพนักงานกับรหัสผ่าน มี 2 สิทธิ์ คือ Admin และ Staff

| รหัส | เอกสาร |
|---|---|
| DP | ใบรับเงินมัดจำ (ลูกค้า → HUGLAO) |
| RC | ใบเสร็จยอดคงเหลือ |
| IV | ใบแจ้งหนี้ถึงลูกค้า เรียกเก็บยอดคงเหลือ (ราคาขาย − มัดจำ) ออกได้หลังออก DP แล้ว |
| RC | ใบเสร็จยอดคงเหลือ ออกให้ลูกค้าในนามบริษัท |
| ~~CR~~ | เลิกใช้แล้ว (2026-09-14) ระบบปฏิเสธถ้ามีการสั่งออก CR ใหม่ |
| PV | ใบสำคัญจ่าย (ค่าใช้จ่ายภายใน แนบสลิปได้ 1 รูป ไม่เกิน 5 MB ผูกกับงานได้ถ้าต้องการ) |

## กติกาธุรกิจ
- ราคาขาย = ราคารถ + ค่านายหน้า
  - ฟอร์มงานมี 3 ช่อง เป็นเงินบาททั้งหมด: ราคารถตู้ / ค่านายหน้า / ราคาขายลูกค้า
  - ค่านายหน้าคิดให้อัตโนมัติตามค่าเริ่มต้น 25% และแก้เองได้
  - % ไม่มีช่องให้กรอก ระบบคำนวณเองแล้วเก็บใน `commission_pct`
- มัดจำเท่ากับค่านายหน้า และจ่ายให้ HUGLAO
- **เอกสารยึดแบบบริษัทขายบริการทั้งทริป** (เจ้าของตัดสินใจ 2026-09-14)
  - ในทางปฏิบัติ ยอดคงเหลือลูกค้าจ่ายเงินสดให้รถตู้ ถือว่ารถตู้รับเงินแทนบริษัท
  - ใบเสร็จทุกใบออกในนามบริษัท ไม่ต้องระบุว่ารถตู้รับเงินแทน
  - ค่าจ้างรถตู้ลงเป็น PV หมวด "ค่าจ้างรถตู้" วิธีจ่าย "หักกลบ / Offset" ผูกกับงาน และให้เจ้าของรถเซ็นรับ
  - รายรับคือ DP + RC ต้นทุนคือ PV ค่าจ้างรถตู้ ส่วนต่างคือกำไร เช่น รับ 1,250 จ่ายรถ 1,000 กำไร 250
  - ลำดับเอกสารของงานหนึ่งงาน: DP → IV → RC → PV ค่าจ้างรถตู้
  - บริษัทยังไม่จด VAT และไม่หักภาษี ณ ที่จ่ายตอนจ่ายรถ
  - แนะนำให้มีหนังสือตกลงกับเจ้าของรถ และให้นักบัญชียืนยัน
- เอกสารเป็นไทยและอังกฤษ ใช้เงินบาทเท่านั้น
- เลขที่เอกสารรูปแบบ `CODE-YYMM-NNNN` เรียงต่อเนื่อง ไม่มีเลขขาด
- ไม่มีทะเบียนลูกค้า ให้พิมพ์ชื่อและเบอร์ลงในงานแต่ละงาน
- มีทะเบียนรถตู้ แต่รถที่ไม่อยู่ในทะเบียนก็กรอกเองในงานได้ ผ่านตัวเลือก "✎ กรอกเอง" ข้อมูลเก็บที่ `van_name` / `van_phone` ใช้เมื่อ `van_id` ว่าง
- ยกเลิกเอกสารได้เฉพาะ Admin และต้องยกเลิก RC ก่อน DP
- พนักงานปิดใช้งานได้อย่างเดียว ลบไม่ได้
- หมวด PV: ค่าจ้างรถตู้ (เลือกวิธีจ่ายแบบหักกลบได้เฉพาะหมวดนี้), น้ำมัน, ค่าจ้าง/เงินเดือน, ค่าเช่า, ค่าโฆษณา, ค่าน้ำ/ค่าไฟ/อินเทอร์เน็ต, ค่าเดินทาง, ค่าอุปกรณ์สำนักงาน, อื่นๆ
- ทำ PDF โดยเปิดหน้า A4 แล้วสั่ง "พิมพ์ / บันทึกเป็น PDF" จากเบราว์เซอร์

## สถานะ
- เสร็จครบ 4 plan มี tag plan-1-foundation, plan-2-bookings, plan-3-documents และ plan-4-operations
- แก้ปัญหา "This page couldn't load" แล้ว (commit 5bd17c1)
  - สาเหตุคือ Supabase ตอบ 504 เป็นครั้งคราว
  - ตอนนี้ระบบลองดึงข้อมูลใหม่อัตโนมัติสำหรับคำขอแบบ GET/HEAD
  - ถ้า auth ตอบ 504 จะไม่เด้งไปหน้า login แล้ว

  - `getCurrentStaff()` ในแต่ละหน้ายังใช้ `getUser()` และเช็กว่าพนักงานยังเปิดใช้งานอยู่ ส่วนความปลอดภัยของข้อมูลยังคุมด้วย RLS

  - ไม่ได้เปลี่ยน getCurrentStaff ไปใช้ getClaims โดยตั้งใจ เพราะถ้าเปลี่ยน การออกจากระบบจากเครื่องอื่นจะมีผลช้าไปถึงประมาณ 1 ชั่วโมง
