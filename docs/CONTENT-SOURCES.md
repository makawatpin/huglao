## หลักการเผยแพร่

- ไม่คัดลอกข้อความจากแหล่งข้อมูลแบบคำต่อคำ แต่สรุปเฉพาะข้อเท็จจริงที่เกี่ยวข้องกับการวางแผนทริป
- เวลาเปิด–ปิด ค่าบัตร กิจกรรม สภาพอากาศ และสภาพเส้นทางเป็นข้อมูลเปลี่ยนแปลงได้ ต้องตรวจอีกครั้งก่อนเดินทาง
- ไม่เพิ่มปลายทางนอกกลุ่มเส้นทางที่ HUGLAO ยืนยัน
- ที่มาภาพและใบอนุญาตเก็บแยกไว้ใน `docs/IMAGE-LICENSES.md` และหน้า `/image-credits`

## สถานะข้อมูลราคา

- Contentful ปัจจุบันมีเฉพาะ content type `article` และยังไม่มี content type ราคา
- ระบบจะอ่านราคาจาก Contentful ต่อเมื่อกำหนด `CONTENTFUL_PRICE_CONTENT_TYPE` หลังสร้างชนิดข้อมูลราคาเรียบร้อยแล้ว เพื่อไม่ให้เว็บไซต์ส่งคำขอไปยังชนิดข้อมูลที่ไม่มีอยู่
- ไฟล์ `preview.xlsx` ถูกคัดลอกเข้าพื้นที่ชั่วคราวเพื่อรอตรวจ โดยไม่แก้ไขไฟล์ต้นฉบับ
- ยังไม่เผยแพร่ตัวเลขจากไฟล์ดังกล่าว เพราะเซสชันนี้ไม่มีเครื่องมือตรวจสเปรดชีตที่กำหนดไว้ จึงยังยืนยันสูตร แถวราคา หมวดรถ และสถานะอนุมัติไม่ได้
- หน้าเว็บแสดงสถานะตรงไปตรงมาและนำผู้ใช้ไปขอราคาผ่าน LINE แทนการใส่ตัวเลขประมาณการ
