# รูปแบบการ์ดสำหรับการใช้งานผ่านมือถือ

เว็บไซต์ HUGLAO เน้นใช้งานผ่านมือถือ ตามคำสั่งเจ้าของวันที่ 5 พฤศจิกายน 2569

- ใช้ `ContentCard` สำหรับรายการที่ลูกค้าเลือกเข้าไปดูต่อ เช่น เมือง เส้นทาง บริการ และบทความ ทั้งใบเป็นลิงก์เดียว ไม่มีปุ่มหรือลิงก์ซ้อนกัน
- มือถือ: การ์ดภาพย่อซ้ายประมาณ 32% และข้อความขวา ชื่อหัวข้อขนาด 16px ขึ้นไป คำโปรยไม่เกินสองบรรทัด ป้ายอ่านต่อชัดเจน และเว้นช่องว่างระหว่างใบ
- รายการไม่มีภาพใช้การ์ดข้อความ ไม่สร้างภาพแทนหรือทำให้ดูเหมือนปุ่มที่กดไม่ได้
- จอใหญ่กลับเป็นรูปด้านบนและข้อความด้านล่างตาม grid ของแต่ละหน้า
- วันที่/ผู้เขียนเก็บไว้ใน DOM และแสดงบนจอใหญ่ ตัวกรองหมวดบทความยังอยู่และเพิ่มพื้นที่แตะเป็นอย่างน้อย 44px
- ปรับหน้าแรก หน้าบทความรวม หน้าบริการรวม และรายการเส้นทางในหน้าเที่ยวลาวกับเรา ใช้ component และ CSS ร่วมกันเพื่อให้เปลี่ยนรูปแบบต่อได้จากจุดเดียว
- ลดระยะห่าง section และหัวข้อหน้าแรกบนมือถือ รักษา H1/H2/H3 และ focus outline สำหรับการเข้าถึง
- เนื้อหาบทความฉบับเต็ม ตารางราคา และเงื่อนไขยังใช้รูปแบบอ่านต่อเนื่อง ไม่แปลงทุกย่อหน้าเป็นการ์ดที่ไม่มีปลายทาง

ตรวจหน้าแรกใน IAB ที่ viewport 390×844: การ์ดกว้าง 343px สูงตั้งแต่ 129px ขึ้นไป และ document width ไม่เกิน viewport ตรวจภาพการ์ดเส้นทางจริงแล้ว หน้ารวมบทความแสดงการ์ดและตัวกรองครบ แต่การกดตัวกรองในแท็บตรวจไม่จบเนื่องจากแท็บหมดการเชื่อมต่อ ไม่รายงานว่าได้ทดสอบตัวกรองผ่าน คืน viewport override แล้ว

HTTP 200 และ markup การ์ดผ่านใน `/`, `/articles/`, `/services/`, `/travel-with-us/` ตรวจ TypeScript และ ESLint ไม่มีปัญหาหลังแก้ import ที่ไม่ใช้ ไม่เพิ่ม dependency หรือแก้ราคา/เนื้อหาบทความ
