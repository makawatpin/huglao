# จัดหมวดบัตรผ่านแดนและลานจอดรถ — 5 พฤศจิกายน 2569

อัปเดตคำค้นหน้าลานจอดรถ: ใช้ “ที่จอดรถหน้าด่านหนองคาย” เป็นคำหลักใน title, H1, meta description และข้อความลิงก์บริการ ส่วนหัวข้อ/เนื้อหา/FAQ ใช้ฝากรถหนองคาย จอดรถไปลาว ฝากรถข้ามไปลาว ฝากรถค้างคืนหนองคาย ค่าจอดรถด่านหนองคาย ที่จอดรถไปเวียงจันทน์ ที่จอดรถพร้อมรถรับส่งด่าน และใกล้สะพานมิตรภาพไทย–ลาวตามบริบท คง URL ราคา บทบาทผู้ประสานของ HUGLAO และสถานะ noindex รอตรวจเดิม

- ใช้เนื้อหาเดิมจากบทความ `temporary-border-pass-xl-parking` แทนหน้าบริการเก่าที่ `/services/temporary-border-pass/` ทั้งภาพ รายละเอียดเอกสาร ค่าใช้จ่าย ขั้นตอน และ FAQ โดยไม่แก้ราคาจากการคาดเดา
- ย้ายเนื้อหาลานจอด XL parking ไป `/services/xl-parking/` และเพิ่มในข้อมูลบริการกลาง ทำให้แสดงในหน้าบริการอื่น ๆ หน้าแรก และ footer
- ปรับ canonical และ breadcrumb ให้ตรงหมวดบริการ และปรับลิงก์ภายในที่อ้างบทความเดิมให้เข้าปลายทางโดยตรง
- สองรายการไม่แสดงในหน้ารวมบทความแล้ว แต่ยังเก็บ slug เดิมในทะเบียนเพื่อป้องกันบทความซ้ำจาก Contentful
- URL บทความเดิมยังมีหน้า meta refresh และลิงก์สำรองไปบริการใหม่สำหรับ local/static hosting; เพิ่ม permanent redirect ใน `vercel.json` สำหรับเมื่อเผยแพร่บน Vercel ไม่มีการ deploy ในงานนี้
- คง noindex ของเนื้อหาพาร์ตเนอร์ที่รอตรวจตามไฟล์ต้นฉบับ ไม่เปิด index เอง และไม่ใส่สองหน้านี้ใน sitemap ระหว่างที่ยัง noindex
- ใช้ภาพที่มีอยู่และมีบันทึกสิทธิ์ในโปรเจค เพิ่มรายการคลังเครดิตสำหรับภาพบัตรผ่านแดนและภาพมุมสูงลานจอด

ไฟล์สำคัญ: `app/services/temporary-border-pass/page.tsx`, `app/services/xl-parking/page.tsx`, `app/services/[slug]/page.tsx`, `app/services/page.tsx`, หน้า alias ใน `app/articles/` สองเส้นทาง, `data/site.ts`, `data/articles.ts`, `data/media.ts`, `app/page.tsx`, `app/sitemap.ts`, `vercel.json`

ตรวจ local ทั้งหน้าบริการรวม หน้าบริการสองรายการ หน้าบทความรวม และ URL บทความเดิม ได้ HTTP 200; ตรวจลิงก์การ์ดและ breadcrumb ผ่าน ไม่มีการเปลี่ยนการส่งข้อความหรือเพิ่มแบบฟอร์ม
