# หน้าแรก HUGLAO — การเดินทางที่เริ่มได้หลายเมือง

ปรับ 5 พฤศจิกายน 2569 ตามทิศทางธุรกิจล่าสุดของเจ้าของ

## แนวทาง

ใช้ข้อความหลัก “เที่ยวลาว ในแบบที่คุณอยากไป” ให้ภาพรวมเป็นแบรนด์ช่วยวางแผนและดูแลรายละเอียดการเดินทาง พร้อมเส้นทางแนะนำและบริการสนับสนุนหลายประเภท ไม่มีข้อความจำกัดว่าจัดหารถอย่างเดียวหรือทุกทริปต้องเริ่มที่เวียงจันทน์ ใช้คำว่าเส้นทางแนะนำ ทริปส่วนตัว และวางแผนการเดินทางในหน้าแรก

## ลำดับหน้า

1. Hero ภาพภูมิทัศน์และข้อความแบรนด์ พร้อมปุ่มดูเส้นทาง/คุยแผนผ่าน LINE
2. การ์ด 3 วิธีเริ่มต้น: เลือกเส้นทางที่ชอบ ให้ช่วยวางแผน หรือเลือกบริการเดินทาง
3. การ์ด 3 เมือง: เวียงจันทน์ วังเวียง หลวงพระบาง ลิงก์สู่บริการที่มีอยู่จริงและมีลิงก์รวมไปเที่ยวลาวกับเรา
4. เส้นทางแนะนำ 4 เส้นทางจากข้อมูลเดิม ระบุชัดว่าเฉพาะรายการในส่วนนี้เริ่มรับจากเวียงจันทน์
5. ขั้นตอนคุยแผน เลือกบริการ และยืนยันรายละเอียด
6. บริการรถ ตั๋วรถไฟ ไกด์ วางแผน เอกสารผ่านแดน และลานจอดรถ
7. ราคาบริการรถแบบย่อและการ์ดประเภทรถ เป็นส่วนรอง พร้อมบอกชัดว่าไม่ใช่ราคารวมทุกบริการของทริป
8. บทความ 3 รายการ คำถามพบบ่อย และปุ่มคุยแผนผ่าน LINE

ย้ายเมนู “เที่ยวลาวกับเรา” มาอยู่ก่อนเมนูจองรถ ปรับ footer และคำอธิบายองค์กร/metadata กลางให้ตรงกับทิศทางใหม่ หน้าแรกมี metadata และ FAQ schema ตรงกับข้อความที่แสดงจริง

## ขอบเขตและภาพ

- ไม่สร้างโปรแกรมสำเร็จรูป ราคา รายการรวมที่พัก อาหาร กิจกรรม หรือวันออกเดินทางที่ยังไม่มีข้อมูลยืนยัน เส้นทางเดิมเป็นไอเดียให้ตกลงรายละเอียดก่อนจอง
- ใช้ภาพภูมิทัศน์จากคลังที่มีเครดิตและใบอนุญาตเดิม หน้าแรกเชื่อมไปหน้าเครดิตภาพ
- ยังไม่มีภาพสถานที่หลวงพระบางในคลังที่ตรวจสิทธิ์ชัดเจน จึงใช้การ์ดตัวอักษรตกแต่งแทนภาพสถานที่ ไม่ใช้ภาพเมืองอื่นหรือรูปรถแทนวิวเมือง
- คง URL และบริการเดิม ไม่เพิ่ม dependency ไม่เพิ่มฟอร์มขอราคา และไม่ deploy/push/merge

ไฟล์หลัก: `app/page.tsx`, `app/layout.tsx`, `components/SiteFooter.tsx`, `data/site.ts`

ตรวจ local HTTP 200, เนื้อหาครบสามเมือง, ไม่มีถ้อยคำวางตำแหน่งแบรนด์เดิมในเนื้อหาหลัก และลิงก์ภายใน/anchor 25 รายการผ่าน TypeScript และ ESLint ผ่าน การตรวจนี้ไม่ได้รวมภาพ screenshot หรือการทดสอบ layout จริงบนอุปกรณ์มือถือ
