# ตารางราคาแยกเมืองและเงื่อนไขส่วนกลาง

ปรับ 5 พฤศจิกายน 2569

- ใช้ `CityPriceTables` ร่วมกันในหน้าจองรถ หน้ารถตู้ หน้าเที่ยวลาวกับเรา และหน้ารายเมืองทั้งสาม
- หน้ารวมแสดงเวียงจันทน์ 25 รายการ วังเวียง 3 รายการ และหลวงพระบาง 4 รายการ รวม 32 รายการ ทุกเมืองใช้โครงสร้างเดียวกัน: หัวเมือง → หมวดรับ–ส่ง → หมวดเหมาเที่ยว
- ตารางเปรียบเทียบใช้เก๋ง/SUV ซ้าย รถตู้ขวา แสดง “–” เมื่อไม่มี SUV หน้ารถตู้และสองเมืองที่มีเฉพาะรถตู้ไม่แสดงคอลัมน์ SUV
- ราคาอ่านจากข้อมูลกลางเดิม ไม่แก้ตัวเลข คงช่วงราคา 1,000–1,200 บาท และหมายเหตุยืนยันจุดรับ–ส่งไว้ในแถว
- รวมเงื่อนไขทั่วไป (สิ่งที่รวม/ไม่รวม เวลา เกินเวลา มัดจำ การตรวจรถ/สัมภาระ และการขอหลายวัน) เป็นส่วนเดียวท้ายตาราง รวมทั้งหมายเหตุขอบเขตบริการรับ–ส่งและการรับฝั่งไทยไว้ในส่วนท้ายนี้
- คงรายละเอียดเฉพาะแถวที่จำเป็น เช่น เส้นทางน้ำตกตาดกวางสีและค่าเข้าสถานที่ ไม่ทำให้ราคาเมืองหนึ่งใช้แทนอีกรายการ
- ลบเงื่อนไขเต็มชุดที่ซ้ำในหน้ารายเมืองและหยุดประกอบตารางเวียงจันทน์กับตารางท้องถิ่นคนละรูปแบบ อัลบั้มยังอยู่หลังตารางและเงื่อนไข
- `ServicePriceOverview` เหลือ wrapper ที่ส่งไฮไลท์ไป `PriceHighlights` และตารางเต็มไป `CityPriceTables` จึงไม่มี renderer ตารางเต็มอีกรูปแบบค้างไว้

ตรวจ local ทั้ง 6 หน้า ได้ HTTP 200 และพบ `data-common-price-terms` เพียงครั้งเดียวต่อหน้า ตรวจจำนวนรายการ 32/25/3/4 และช่วงราคาแล้ว TypeScript ผ่าน ไม่มี dependency เพิ่ม
